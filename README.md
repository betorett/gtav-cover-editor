# Editor de carátula GTA V (PS4)

Web lista para usar online en GitHub Pages: **[https://betorett.github.io/gtav-cover-editor/](https://betorett.github.io/gtav-cover-editor/)**

Usa la carátula original (`base.jpg`) tal cual y permite:

- **Portada (9 viñetas)**: sustituir cualquiera de las 9 fotos manteniendo encima el logotipo oficial `grand theft auto V FIVE`, `MATURE 17+` y `R★`.
- **Contraportada (4 fotos + textos superiores)**: cambiar la foto superior y las 3 capturas, y editar la cabecera superior, la sinopsis y el texto bajo las capturas.

## Uso

1. Abre la web (o `index.html` directamente).
2. Haz clic en una foto para sustituirla, arrastra para encuadrar y usa la rueda para zoom.
3. Edita los textos de la mitad superior de la contraportada desde el panel derecho si quieres personalizarlos.
4. Pulsa **Descargar PNG** para guardar la carátula completa en alta resolución.
